# Лабораторные работы и курсовая по дисциплине «Системы обработки больших данных»

ВолгГТУ, магистратура 09.04.01 «Информатика и вычислительная техника»

Выполняется разведочный анализ и машинное обучение на больших данных
с использованием **Apache Spark (PySpark)**, **HDFS**, **YARN**, **Apache Iceberg**
и **SparkML**.

## Датасет

**BTS Reporting Carrier On-Time Performance, 2019–2023** — данные о пунктуальности
внутренних авиарейсов США (официальная статистика Министерства транспорта США,
[transtats.bts.gov](https://www.transtats.bts.gov/)).

* ~32 млн рейсов за 5 лет, ~15–17 ГБ CSV
* Задача регрессии: величина задержки прибытия `ARR_DELAY` (минуты)
* Задача бинарной классификации: задержка свыше 15 минут (критерий DOT)

Скачивание: `bash scripts/download_bts.sh`

## Структура репозитория

## Рабочий процесс

Вся разработка и выполнение — на кластере кафедры (YARN, окружение `pyspark-env`).
Локально нужен только VS Code с расширениями `Python`, `Jupyter`, `Remote - SSH`:
интерфейс ноутбуков — локальный, ядро и вычисления — на кластере.

Подключение: `ssh -D 12345 -J user@ip:port user@hadoop-node` (см. методичку лабы 1).

Данные один раз скачиваются скриптом `bash scripts/download_bts.sh`, переносятся
на кластер (drag&drop в VS Code / WinSCP) и загружаются в HDFS:

```bash
hdfs dfs -copyFromLocal data/csv /home/<user>/<dir>/data
```
